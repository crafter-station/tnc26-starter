## Sube tu código aquí

La URL exacta de tu repo está en el dashboard, en la pestaña **Equipo**.

**Si empiezan de cero:**

```bash
git clone https://github.com/crafter-station/<tu-repo>.git
cd <tu-repo>
```

**Si ya tienen código en local:**

```bash
git remote add origin https://github.com/crafter-station/<tu-repo>.git
git branch -M main
git push -u --force origin main
```

El `--force` es a propósito: la historia de tu proyecto no tiene relación con la de
esta plantilla, y lo que se reemplaza es este contenido, que es desechable.

> **Acepta la invitación antes de empujar.** Te llegó por correo y está en
> [github.com/notifications](https://github.com/notifications). Sin aceptarla,
> `git push` responde `403` y el mensaje no dice que sea por eso.

Este repositorio es **público**. No subas claves, tokens ni credenciales: usa un
`.env` local, que ya está en el `.gitignore`.
